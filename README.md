# Координата Quest 🎮

Жазықтықтағы және кеңістіктегі координаталар мен векторлар тақырыбына арналған интерактивті математикалық веб-ойын.

## Мүмкіндіктері
- 10 деңгей;
- жазықтық және кеңістік координаталары;
- вектор координаталары;
- вектор ұзындығы;
- ұпай, уақыт және 3 мүмкіндік жүйесі;
- телефонға бейімделген интерфейс;
- GitHub Pages арқылы тегін жариялауға дайын.

## Іске қосу

`index.html` файлын браузерде ашуға болады.

## GitHub Pages

1. GitHub-та жаңа repository ашыңыз, мысалы `coordinate-quest`.
2. Осы үш файлды (`index.html`, `style.css`, `script.js`) және `README.md` файлын repository-ге жүктеңіз.
3. **Settings → Pages** бөліміне кіріңіз.
4. **Deploy from a branch** таңдаңыз.
5. Branch ретінде `main` және `/ (root)` таңдаңыз.
6. Save басыңыз.
7. GitHub сізге ойынның веб-сілтемесін береді.

## Өзгерту

Сұрақтар `script.js` ішіндегі `questions` массивінде орналасқан. Әр сұрақтың:
- `topic` — тақырыбы;
- `q` — сұрақ мәтіні;
- `a` — жауап нұсқалары;
- `correct` — дұрыс жауаптың индексі;
- `ex` — қысқаша түсіндірмесі бар.

Автор: Математика сабағына арналған оқу жобасы.
